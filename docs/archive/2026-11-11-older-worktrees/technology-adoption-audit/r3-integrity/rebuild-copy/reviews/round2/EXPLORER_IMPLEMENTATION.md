The [browser evidence](explorer-ui/BROWSER_QA.json) records **18 full-edition check groups**, **15 viewport observations** and **18 reviewed screenshots**. Testing used headed Google Chrome 156.0.8078.80 through Playwright, with desktop 1440×1000 and mobile 390×844 viewports over a loopback HTTP server. The primary desktop and mobile views expose the three navigation layers and case finder. Long records intentionally scroll. Dense claims, source locators, node/edge scopes, comparisons, route cards and actor disclosures were inspected for wrapping, clipping, overlap and legibility; no unintended horizontal overflow or hidden principal control was found. Representative captures show the [desktop entry](explorer-ui/full-desktop-initial.png), [mobile entry](explorer-ui/full-mobile-initial.png), [mobile section reload](explorer-ui/full-mobile-section-reload.png), [exact claim](explorer-ui/full-claim-rivals.png), [node incidence](explorer-ui/full-node-incidence.png), [source locator](explorer-ui/full-mobile-source-locator.png), [comparison](explorer-ui/full-comparison.png) and [disputed dates](explorer-ui/full-chronology-disputed-dates.png).

Exploration also covered mobile picker opening/closing, case search and strand filtering, empty states without replacing the open record, disclosure cycles, keyboard skip and lookup controls, a local reading-document link, legacy raw IDs, unknown IDs, wrong record kinds, malformed percent encoding, nonexistent routes and inherited-property names. Invalid links explain the problem rather than silently selecting another case. No uncaught JavaScript exception or automatic external request was observed. The preliminary server requested a missing optional local favicon; this did not affect the explorer.

The reproducible [build checker](explorer-ui/verify_explorer_build.py) passed [15 checks](explorer-ui/EXPLORER_BUILD_CHECKS.json): Python and rendered JavaScript syntax, full-snapshot generation, lossless transport of all seven datasets, usable omission of optional chronology, refusal of validation errors, and refusal of malformed, duplicate or unknown chronology references. Negative probes used isolated temporary copies. Existing canonical research, compiled data and the production `index.html` were not changed by this assignment. The parent remains responsible for synchronized production generation and all-contribution parity.

The visual checks sampled consequential views rather than all 88 case pages or 329 claim renderings. Only one Chromium-family browser was used; Safari, Firefox, screen readers and print layout were not audited. Historical accuracy, strength of causal inference and final editorial completeness remain separately reviewed. The browser and local preview server were closed after evidence capture.
