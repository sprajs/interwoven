# Scope/power review: independent source access record

Accessed 5 November 2026. “Full text available” is not a claim that every page, underlying archive or calculation was reviewed. The locators below identify the passages actually used. Reopening the same study is an audit, not additional independent corroboration. No other round-1 review was consulted.
