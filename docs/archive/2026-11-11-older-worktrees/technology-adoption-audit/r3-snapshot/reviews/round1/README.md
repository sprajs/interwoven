# Independent review round 1

The immutable [snapshot](snapshot/MANIFEST.json) contains the first synthesis, methods v2, 59 cases, 210 claims and 129 source records. Source counts do not imply independent corroboration. Five second-wave investigations are running separately and are deliberately excluded from this snapshot.

Three independent Astra reviewers will examine source entailment, causal discrimination, and geographic/political/actor scope. Reviewers must distinguish defects in existing assertions from already disclosed evidence gaps. Findings are resolved in the parent response log and a later revised snapshot is reviewed again.
