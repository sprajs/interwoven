# Integrated inference and method sources

The [second synthesis](../../analysis/SYNTHESIS.md) integrates the completed investigations and review-driven countercases. SYN-K01–K03 describe methodological sources; SYN-K10–K22 (with deliberate gaps) preserve bounded inferences, underlying claim IDs and realistic surviving rivals. SYN-X01–X08 state comparison logic, units and evidence lineage. Stage distinctions and observed coexistence are not labelled as identified general mechanisms.

Canonical claims are compiled from the deliberately authored synthesis_specs.json using tools/build_synthesis_records.py. comparisons.json is separately authored canonical data. Neither is an estimate of mechanism prevalence or a set of independent replications. Follow each underlying claim and source locator before reusing an inference; publication versions and shared datasets remain distinct from independent corroboration.
