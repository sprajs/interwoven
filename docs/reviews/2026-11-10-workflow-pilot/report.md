## Accounting

56 new provider calls, $2.4135 standard API-equivalent estimate, 255 seconds measured from first call start to last call end. Review calls $0.8319; blind judges $1.5816. This is not observed billing. Raw prompts, passages, and judgment explanations are retained privately.

The twelve paired review calls cost $0.0812 for revised Terra-medium and $0.2481 for the saved Sol-medium baseline under the same API-equivalent rates. Extraction is shared and excluded from these review-stage figures.

Confirmation compares both a new prompt and a reviewer-model change against the saved old-prompt baseline; it does not isolate a pure model effect. Confirmation cases were selected before pilot calls, but they were part of the previous 100-case benchmark and are not an untouched external sample. Zero flags in this small model-only sample does not certify historical accuracy.
